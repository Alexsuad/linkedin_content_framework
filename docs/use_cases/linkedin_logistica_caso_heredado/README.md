# Caso Heredado: LinkedIn y Operaciones Logísticas

Este directorio contiene el caso práctico original heredado del proyecto `Automatizacion_linkedin`. Funciona como el primer caso de uso documentado del framework.

---

## Directrices del Caso

*   **Origen Histórico:** Este caso de uso proviene del diseño pre-code original, donde se probó el pipeline de transformación de señales logísticas en contenido B2B.
*   **Caso de Prueba y Aprendizaje:** Sirve como banco de pruebas y referencia práctica para validar el comportamiento de las auditorías de calidad y los flujos del framework.
*   **Independencia del Framework Madre:** La existencia de este caso **no define la identidad global de `linkedin_content_framework`**. El framework madre es independiente de este sector.
*   **Reglas Específicas Acotadas:** Las reglas y configuraciones del perfil editorial logístico (como el comprador objetivo "Director de Tránsito", la aprobación a cargo exclusivo de "Alex", y el ritmo de "3 posts semanales con carrusel los jueves") **permanecen estrictamente dentro de este caso de uso** y no deben propagarse al núcleo general del sistema.
